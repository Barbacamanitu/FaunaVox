// Letter-to-sound rules for English words that aren't in cmudict.dict (made-up names, misspellings),
// after the NRL rules (Elovitz, Johnson, McHugh & Shore, "Automatic translation of English text to
// phonetics by means of letter-to-sound rules", Naval Research Laboratory report 7948, 1976).
//
// Each rule is  LEFT[MATCH]RIGHT=PHONEMES  (ARPAbet, as in cmudict). For each position in a word the
// rules for its letter are tried in order and the first that fits is used. LEFT and RIGHT are context:
//   _  word boundary          #  one or more vowels       :  zero or more consonants
//   ^  one consonant          .  a voiced consonant (B D V G J L M N R W Z)
//   +  a front vowel (E I Y)  %  a suffix (ER E ES ED ING ELY)
//   &  a sibilant (S C G Z X J CH SH)   @  T S R D L Z N J TH CH SH (u after these is "oo")
// Vowels are A E I O U. An empty PHONEMES makes the letters silent.
